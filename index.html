Questions

Does it catch everything?

No tool does. Blot Genie finds most private details and shows you each one, so you make the final check before you save.

Can you see my files?

No. There is no account system and no server that receives documents.

Is my data used to train AI?

No. The model runs on your Mac and nothing you open is sent anywhere.

Do I need an internet connection?

No. It works with Wi-Fi switched off.

Which Macs does it run on?

Macs with Apple silicon running macOS 14 or later.
